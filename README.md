# Master Thesis : Design and Development of a Web-Based Network Device Monitoring and Management System with a Unified Dashboard

A full-stack application for monitoring network devices in real-time, built with **FastAPI** and **React.js**, using **PostgreSQL**, **Redis**, and **Docker**. It collects device metrics (CPU, RAM, traffic, latency, uptime) and displays them on a dashboard with live updates via WebSockets.

---

## Tech Stack

- **Backend:** FastAPI, SQLAlchemy, Alembic, Celery
- **Frontend:** React.js, Chart.js
- **Database:** PostgreSQL
- **Cache / Task Queue:** Redis
- **Containerization:** Docker, Docker Compose
- **Version Control:** Git/GitHub
